## MCP Servers

A huge list of awesome MCP server implementations:

- <img src="https://github.com/nuanu-ai.png" width="20"/> [Agent Payment Node](https://github.com/nuanu-ai/agent-payment-node) - Local macOS CLI and stdio MCP payments with foreground owner approval for signing.
- <img src="https://img.icons8.com/color/24/000000/server.png" width="20"/> [OpenMCP](https://github.com/example/openmcp) - High-performance, open-source MCP server in Go.
- <img src="https://img.icons8.com/color/24/000000/nodejs.png" width="20"/> [MCP.js](https://github.com/example/mcpjs) - Lightweight MCP server in Node.js.
- <img src="https://img.icons8.com/color/24/000000/python.png" width="20"/> [PyMCP](https://github.com/example/pymcp) - Python-based MCP server for rapid prototyping.
- <img src="https://img.icons8.com/color/24/000000/net-framework.png" width="20"/> [MCP.NET](https://github.com/example/mcpnet) - .NET implementation of the MCP protocol.
- <img src="https://img.icons8.com/color/24/000000/rust-programming-language.png" width="20"/> [RustyMCP](https://github.com/example/rustymcp) - Fast and safe MCP server in Rust.
- <img src="https://img.icons8.com/color/24/000000/java-coffee-cup-logo.png" width="20"/> [MCP4J](https://github.com/example/mcp4j) - Java MCP server for enterprise applications.
- <img src="https://img.icons8.com/color/24/000000/cloud.png" width="20"/> [MCP-Cloud](https://github.com/example/mcp-cloud) - Scalable MCP server for cloud deployments.
- <img src="https://img.icons8.com/color/24/000000/microchip.png" width="20"/> [MCP-Lite](https://github.com/example/mcp-lite) - Minimal MCP server for embedded systems.
- <img src="https://img.icons8.com/color/24/000000/edge-computing.png" width="20"/> [MCP-Edge](https://github.com/example/mcp-edge) - Edge-optimized MCP server.
- <img src="https://img.icons8.com/color/24/000000/experimental.png" width="20"/> [MCP-Experimental](https://github.com/example/mcp-experimental) - Experimental features and research.

## Tools

Tools for working with MCP:

- <img src="https://img.icons8.com/color/24/000000/inspection.png" width="20"/> [MCP Inspector](https://github.com/example/mcp-inspector) - Debugging and inspection tool for MCP traffic.

1. Fork this repository.
2. Create a new branch (`git checkout -b feature/your-feature`)
3. Add your entry or improvement.
4. Commit your changes (`git commit -am 'Add new MCP server/tool/resource'`)
5. Push to the branch (`git push origin feature/your-feature`)
6. Open a Pull Request.

Please make sure your entry is not a duplicate and follows the format of existing entries. See [CONTRIBUTING.md](CONTRIBUTING.md) for more details.
